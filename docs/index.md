# Documentation

Crusader SDK is an unofficial Python client and bridge for Stronghold Crusader. You must supply your own supported game files; the SDK does not include the game.

- [Quickstart](quickstart.md): install the client and run the experimental Docker setup.
- [Concepts](concepts.md): ticks, coordinates, IDs, events, and refusals.
- [API reference](api.md): client methods and arguments.
- [Protocol](protocol.md): HTTP, MCP, authentication, and response behavior.
- [How it works](how-it-works.md): game integration and memory boundary.
- References: [state](reference/state.md), [events](reference/events.md), [buildings](reference/buildings.md), [units](reference/units.md), [goods](reference/goods.md), [map legend](reference/map-legend.md), and [errors](reference/errors.md).
